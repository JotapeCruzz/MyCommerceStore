# 🇧🇷 README — Projeto MyStore

MyStore é um aplicativo de e-commerce desenvolvido em **Flutter**, utilizando Provider, Firebase e arquitetura modularizada. O app oferece gerenciamento de produtos, carrinho, favoritos, autenticação e telas organizadas.

---

## 📦 Funcionalidades

* 📱 **Listagem de produtos**
* 🛒 **Carrinho com Provider**
* ❤️ **Wishlist / Favoritos**
* 🔐 **Autenticação (Firebase pronto para integrar)**
* 🗂️ **Arquitetura limpa com repositórios e serviços**
* 🎨 **Widgets reutilizáveis**
* 🚦 **Rotas centralizadas**

---

## 📂 Estrutura do Projeto

```
lib/
├── app.dart
```

## ▶️ Como Executar

1. Instale dependências:

# 🇺🇸 README — MyStore Project

MyStore is an e-commerce mobile application built with **Flutter**, using Provider state management, Firebase setup, modular architecture, and reusable widgets. The app includes products, cart, wishlist, authentication structure, and organized pages.

---

## 📦 Features

* 📱 **Product listing**
* 🛒 **Cart managed with Provider**

* 🔐 **Authentication ready (Firebase)**
